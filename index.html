Firebase Setup Required
  1. Go to console.firebase.google.com and sign in with Google
  2. Click Add Project → name it forge-coaching → click through and create
  3. In the left sidebar click Firestore Database → Create database → choose Start in test mode → pick any region → Done
  4. Click the ⚙️ gear icon (top left) → Project settings → scroll to Your apps → click </> Web icon → register app with any name
  5. Copy the firebaseConfig object shown and paste it below
After setup: Host this file on Netlify Drop (free) and share the link with your clients. Everyone's data syncs in real time.
